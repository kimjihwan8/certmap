# 정답지 라벨링 기준

질문은 하나다: **이 인증을 받은 영업장이, 후보 중 어느 상가 가게인가?**

한 건마다 답은 셋 중 하나다.

| 답 | 뜻 |
|---|---|
| 후보 번호 (1~9) | 그 상가 가게가 인증받은 바로 그 영업장이다 |
| `N` | 후보 중에 그 영업장이 없다 |
| `U` | 주어진 정보로는 판단할 수 없다 |

후보는 모두 인증 주소와 **같은 건물**에 있는 상가 가게다. 주소는 이미 맞으니 **이름과 업종**으로 판단한다.

## 같은 가게로 본다

- 표기만 다르다: 띄어쓰기, 괄호, `(주)`·`주식회사`, 영문 병기, 지점명을 붙였는지 뗐는지
  - `쁘띠하노이(서울역점)` = `쁘띠하노이 서울역점`
  - `지어앤 (CHOEN)` = `지어앤`
- 오타·한두 글자 차이이고 업종이 맞다: `미도리회집` = `미도리횟집`
- 한쪽이 줄여 적었고 업종이 맞다: `청진옥` = `청진`, `들풀식당` = `들풀`
- 인증 이름에 법인명 + 상호가 같이 있고, 상가는 그중 하나만 적었으며 업종이 맞다
  - `(주)에스와이에스홀딩스 이남장설렁탕 전자랜드점` = `에스와이에스-이남장`
- 상가 업종이 카페·주점 등 인증 소스와 조금 달라도, 이름이 같으면 같은 가게다 (식품안심업소·관광공사에는 카페가 많다)

## 다른 가게로 본다 (그 후보를 고르지 않는다)

- 이름은 겹치지만 업종이 영업장 성격과 다르다
  - `한우촌`(식당) ≠ `한우촌판매장`(정육점)
  - `(주)조선호텔앤리조트 스시조`(식당) ≠ `조선호텔앤리조트`(호텔). 호텔 안 식당과 호텔은 다른 영업장
  - `남도미항 용산아이파크몰점` ≠ `용산아이파크헤지스`(의류). 건물 이름이 겹친 것뿐
- 같은 브랜드의 다른 지점이 분명하다: 지점명이 서로 다르다 (`OO 강남점` ≠ `OO 역삼점`)
- 이름이 완전히 다르다. 가게가 이름을 바꿨을 수도 있지만 확인할 수 없으면 같은 가게로 보지 않는다

## 여러 후보가 그럴듯할 때

- 지점명·층·업종이 인증과 더 잘 맞는 쪽을 고른다
- **상가에 같은 가게가 두 번 실린 경우**: 이름·지점명이 같고 서로 다른 가게라고 볼 근거가 없으면 (업종 소분류만 조금 다른 것도 포함, 예: 써브웨이가 '피자'와 '샌드위치'로 두 번) 해당 번호를 모두 `|`로 이어 적는다. 예: `1|2`. 어느 쪽을 골라도 정답으로 친다
- 단, 업종이 성격부터 다르면 중복이 아니다: `한우미강정육식당`(식당) / `한우미강정육식당`(정육점) → 인증이 식당이면 식당 쪽 하나만
- 서로 다른 가게일 수 있는데 구별할 정보가 없으면 `U`

## 휴게소·공항·푸드코트의 코너 단위 인증

인증은 "OO휴게소 우동 코너", "푸드코트 [남산왕돈까스]"처럼 코너 하나에 붙는 경우가 많다.

- 상가에 그 코너가 따로 실려 있으면 → 그 후보
- 상가에 코너들이 하나하나 따로 실려 있는데 인증받은 코너만 없으면 → `N`
- 상가에 휴게소·푸드코트 운영사 한 줄만 있으면 → `U` (코너와 운영사를 같은 영업장으로 볼 수 없다)

## N 과 U 의 구분

- `N`: 후보를 다 봤는데 그 영업장으로 볼 만한 게 없다. (상가에 없거나, 이름이 바뀌어 알아볼 수 없음)
- `U`: 그럴듯한 후보가 있지만 같은 가게인지 확신할 근거가 부족하다, 또는 둘 이상이 똑같이 그럴듯하다

헷갈리면 `U`를 쓴다. 틀린 확정보다 `U`가 낫다. `U`는 채점에서 빼거나 사람이 다시 본다.

## 하지 않는 것

- 규칙이 무엇을 골랐을지 추측하지 않는다. 오직 "같은 영업장인가"만 판단한다.
- 화면에 안 보이는 정보를 지어내지 않는다.
